# 拾知鱼形 Icon（第一版）

## 设计含义

- **鱼**：代表在网页信息流中游动、发现和拾取内容。
- **鱼腹负形**：同时像翻起的知识页与水纹，对应“提取正文 → AI 理解 → 归档”。
- **青绿色尾鳍**：由两片信息碎片组成，表达持续收集与积累。
- **信息拾取点**：表现网页片段进入工作流。
- **深蓝 + 青绿**：深蓝强调可靠的知识管理，青绿呼应项目现有的工作模式与完成状态。

## 文件

- `shizhi-fish-icon.svg`：1024×1024 矢量源文件，适合继续修改与导出多尺寸。
- `shizhi-fish-icon.png`：1024×1024 PNG 预览。
- `shizhi-fish-icon-128.png`：128×128 小尺寸预览。
- `shizhi-fish-icon-40.png`：40×40，模拟当前悬浮按钮的实际显示尺寸。
